# Media Transform System

This is a project where I want to create a media system that I can use to alter videos and images instead of using online ones. Right now, it is mainly the video transformer, where I am able to convert video files to different formats.

## What I can alter
- I can rename the file
- I can change the file format
- I can remove streams from the video
- I can change the fps
- I can change the file size
- I can change the audio channel
